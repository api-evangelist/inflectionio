# Inflection.io

> Inflection is a B2B marketing automation platform — a modern, AI-native replacement for legacy tools like Marketo — that unifies target accounts, product users, customers, and leads with product-usage, sales, and behavioral signals to build audiences, draft campaigns, map journeys, and report to the CMO. The Inflection Developer API is a JSON-over-HTTPS REST API for reading and writing the people in your workspace: their profiles, product and marketing activity, static lists, and email templates.

## API
- [Inflection Developer API (OpenAPI 3.1)](https://raw.githubusercontent.com/api-evangelist/inflectionio/refs/heads/main/openapi/inflectionio-openapi-original.yml): 18 operations across Contacts, contact activity, Lists & members, and Email templates. Base https://api.inflection.io/v1. Bearer Personal Access Token (READ/WRITE scopes). Live Swagger UI at https://api.inflection.io/docs.
